# STEP 1 — Install circom + snarkjs

```bash
npm install -g snarkjs
```

Install circom:
https://docs.circom.io/getting-started/installation/

Verify:

```bash
circom --version
snarkjs --version
```

---

# STEP 2 — Download PTAU (ONLY ONCE)

```bash
mkdir ptau
```

Download:

```bash
curl -L \
https://storage.googleapis.com/zkevm/ptau/powersOfTau28_hez_final_17.ptau \
-o ptau/powersOfTau28_hez_final_17.ptau
```

---

# DEPOSIT CIRCUIT

## STEP 3 — Compile Deposit Circuit

```bash
circom circuits/deposit_proof.circom \
    --r1cs \
    --wasm \
    --sym \
    -o build
```

## STEP 4 — Generate Deposit ZKey

```bash
snarkjs groth16 setup \
    build/deposit_proof.r1cs \
    ptau/powersOfTau28_hez_final_17.ptau \
    build/deposit_0000.zkey
```

## STEP 5 — Finalize Deposit ZKey

```bash
snarkjs zkey contribute \
    build/deposit_0000.zkey \
    build/deposit_final.zkey \
    --name="mahesh"
```

## STEP 6 — Export Deposit Verifier

```bash
snarkjs zkey export solidityverifier \
    build/deposit_final.zkey \
    contracts/DepositVerifier.sol
```

DONE.
