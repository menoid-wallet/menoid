Base MAINNET (v1-mainnet) — the runbook

    The second mainnet (chain 8453), the same guarded launch as Monad: small
    per-deposit caps, one funded wallet as deployer + owner + relayer (the
    same key and the same relayer identity as Monad mainnet), Uniswap's own
    V3 deployment, the same trusted setup (ceremony/v1m-mainnet).

1. Gas on Base

    Base's whole gas price is ~0.006 gwei (base fee 0.005 + tip ~0.001), plus
    a tiny L1 data fee. Library defaults assume Ethereum's 1-2 gwei tips —
    hundreds of times too much — so hardhat.config.js fixes baseMainnet's gas
    price at 0.012 gwei (BASE_GAS_PRICE_WEI overrides). The whole deploy (57
    transactions, 11M gas) cost ~$0.30. A relayed private transaction costs
    the relayer ~$0.01-0.03.

2. RPCs (free ones, as of 2026-10-15)

    mainnet.base.org          sending works, but it hung once mid-deploy (the
                              deploy stopped after the adapter; see 4), and it
                              refuses eth_getLogs entirely
    base-rpc.publicnode.com   fast reads, eth_getLogs over the last ~5,000
                              blocks only (~3 hours); older state: "archive
                              requests require a personal token"
    base-mainnet.public.blastapi.io   serves old state; sent the rest of the deploy

    The backend reads and indexes through publicnode (config.js BASE_MAINNET).
    Kept awake (UptimeRobot / HetrixTools ping), it never falls 3 hours behind;
    if it might, set V1M_BASE_LOGS_RPC_URL to an endpoint with archive logs.

3. Deploy (done) — rehearse on a fork first

    FORK_CHAIN_ID=8453 npx hardhat node --fork https://base-mainnet.public.blastapi.io --port 8548
    npx hardhat run scripts/deploy.js --network baseMainnetFork        (free; mine one block first)
    npx hardhat run scripts/deploy.js --network baseMainnet

4. If a deploy stops part-way (it did: an RPC timeout after the adapter)

    BASE_MAINNET_RPC_URL=https://base-mainnet.public.blastapi.io \
    POOL=0x436968db6B2B8E729cB21498030c5ebFa4ad0CE6 DEPLOY_BLOCK=52632857 \
    ADAPTER=0x30Eb860540aB57523Cb8E35f78B37D89658F2595 \
      npx hardhat run scripts/resume-deploy.js --network baseMainnet

    It reads the chain, accepts the tokens the pool does not accept yet,
    registers the relayer if needed and writes deployments/baseMainnet.json.
    Safe to re-run.

5. More tokens later

    Add them to helpers/mainnet-tokens.js (checked the same way), then
    npx hardhat run scripts/list-tokens.js --network baseMainnet
    and add them to website/backend/v1mainnet/config.js (with a logo in
    website/public/tokens/base/).

6. The backend (the same server as Monad mainnet)

    V1M_CHAINS=monad,base on Render. Base's addresses are config.js defaults;
    nothing else to set. The first price pass after a start takes ~30 s.
