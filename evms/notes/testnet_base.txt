Base Sepolia (v1-mainnet)

    Menoid v1-mainnet runs on Base Sepolia (chain 84532) next to Monad testnet,
    against Uniswap's OWN V3 deployment and its existing WETH/USDC pools.
    Same contracts and circuits as Monad testnet; same testnet keys (one
    signature gives the same identity on both chains, registered per pool).

    Records   deployments/baseSepoliaV1m.json            Menoid addresses
              deployments/baseSepoliaV1m-uniswap.json    Uniswap's addresses, pools, test token
              .openzeppelin/base-sepolia.json            upgrade manifest (commit it)
    Network   hardhat network `baseSepoliaV1m`. `baseSepolia` and
              deployments/baseSepolia.json are the V1 DEMO's: untouched.
    Secrets   .env (PRIVATE_KEY, BASE_SEPOLIA_RPC_URL, RELAYER WALLET block)

2. Running it again

    npx hardhat run scripts/testnet/setup-uniswap-official.js --network baseSepoliaV1m
    npx hardhat run scripts/deploy.js --network baseSepoliaV1m

    setup-uniswap-official.js is resumable; deploy.js deploys a NEW pool every
    time. Cost of this deployment: ~0.00004 ETH of gas, plus ~0.0043 ETH
    swapped into the USDC that seeds the mTKN pool.

    The relayer's fees here (0.006 gwei): ~$0.021 a transfer or withdraw,
    ~$0.024 a swap. Ethereum-priced gas: ~1.04M a transfer (Monad bills ~2x).


4. Base facts that matter

    a. Gas is billed on gas USED (Monad bills the limit), plus an L1 data fee
       for the calldata. The relayer's fee model reads the fee from the
       GasPriceOracle predeploy (0x42...0F, getL1FeeUpperBound): ~1.6 KB per
       proof; near zero on Sepolia, about $0.0002 a transaction on mainnet.
    b. eth_getLogs: the public endpoint (sepolia.base.org) allows 200-block
       ranges; free tiers of RPC providers allow 10. The backend reads logs
       from the public endpoint in 150-block windows and sends through the
       private one.
    c. RPC load balancers can answer from a node a block behind: read state
       right after a transaction with a retry (helpers/deploy.js does).
    d. Testnet pool prices are whatever their liquidity providers set: the
       0.30% pool pays ~4,900 USDC per ETH. The app prices ETH at Base
       MAINNET's WETH/USDC mid price, so a quote can read "$2.37 in, $4.87 out".
