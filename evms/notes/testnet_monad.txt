Monad Testnet (v1-mainnet)

    Menoid v1-mainnet runs on Monad testnet (chain 10143) for testing.
    Mainnet uses none of it: another network name, other keys, Uniswap's own
    deployment, a multisig owner and a real trusted-setup ceremony (section 5).

2. Running it again

    npx hardhat run scripts/testnet/deploy-uniswap.js --network monadTestnet
    npx hardhat run scripts/deploy.js --network monadTestnet
    npx hardhat run scripts/testnet/e2e.js --network monadTestnet

    deploy-uniswap.js and e2e.js skip what is already done, so a failure
    halfway is fixed by running them again. deploy.js deploys a NEW pool
    every time. To repeat the e2e on the same pool, move
    monadTestnet-e2e.json away first (the wallets file is reused).

    Rehearse on a local fork of Monad testnet first; nothing reaches the chain:

    npx hardhat node --fork https://testnet-rpc.monad.xyz --port 8546
    WRAPPED_NATIVE=0xFb8bf4c1CC7a94c73D209a149eA2AbEa852BC541 \
        npx hardhat run scripts/testnet/deploy-uniswap.js --network monadTestnetFork
    npx hardhat run scripts/deploy.js --network monadTestnetFork
    npx hardhat run scripts/testnet/e2e.js --network monadTestnetFork


3. What the end-to-end run covered

    alice, bob, carol registered (testnet keys); dave never did.

    deposits      mUSDC and native MON, and bob depositing into carol's balance
    transfers     single note, two notes in one proof, two transfers in one
                  relayer transaction, a note bought in a swap
    withdrawals   mUSDC to dave, native MON (unwrapped WMON) to dave, the mTKN
                  carol bought
    swaps         chosen by findBestRoute on the live pools: a small trade went
                  through the 0.05% pool, bigger ones through the deeper 0.30%
                  pool, WMON -> mTKN as two hops through mUSDC
    viewing keys  full / incoming / epoch keys; an epoch key sees one period
                  only; the full key sees all of alice's payments and none of
                  bob's notes
    attacks       12 refused with eth_call (no gas): a withdrawal redirected,
                  enlarged, or its fee claimed by someone else; an unknown
                  root; a double spend; a replay; an expired swap; an
                  unmeetable minimum; a non-owner configuring or upgrading;
                  an unaccepted token; a transfer to an unregistered address
    upgrade       the live proxy accepts the current code (validated only)
    books         every private balance equals the ledger of the steps, and
                  the pool holds exactly the sum of all unspent notes

    Gas spent by the run: 4.08 MON. Deploying Uniswap and Menoid: about 5 MON.


4. Monad facts that matter (measured here)

    a. Gas is charged on the gas LIMIT, at base fee + tip (base fee floor
       100 gwei). Receipts report gasUsed = gasLimit. Set the limit to
       eth_estimateGas plus a small margin; the e2e used +10%, and paid it.

    b. A proof costs about twice what Hardhat reports. Monad prices the
       BN254 precompiles higher (ecPairing 225,000 per pair vs 45,000;
       ecMul 30,000 vs 6,000) and cold storage / account access too:

                                  Monad    Hardhat (Ethereum prices)
        register                   184k         165k
        deposit (ERC-20)           0.71-1.05M   0.68-1.02M
        deposit (native)           691k         677k
        transfer                   2.06M        1.04M
        two transfers, one tx      4.01M        1.95M
        withdraw                   2.10M        1.04M
        swap, 1 hop                2.43M        1.24M
        swap, 2 hops               2.57M        1.33M

       A private transfer costs about 0.21 MON with an exact limit (0.23 with
       +10%). The earlier mainnet cost estimates used Ethereum prices: double
       them for proofs.

    c. Reserve balance. Every account keeps a 10 MON reserve. An account
       below it may send value (msg.value) only in its first transaction in
       the last 3 blocks; otherwise the transaction reverts and still pays
       gas. So a native deposit from a small wallet waits 3 blocks after
       that wallet's previous transaction (e2e.js waitForReserveWindow). The
       website must do the same. ERC-20 deposits send no value.

    d. eth_getLogs: read 100-block windows (PoolMirror maxBlockRange). At
       0.3 s per block, 100 blocks are 30 seconds.

    e. The public RPC rate-limits (about 15-25 requests a second):
       helpers/rpc.js ResilientProvider throttles and retries.

    f. Native MON out works through the proxy: the real WMON pays the proxy
       under Monad's gas prices.


5. Why mainnet is not affected

    - Separate names: monadTestnet / monadTestnetFork here; the V1 demo keeps
      `monad`; mainnet will get its own.
    - Separate keys: everything here was derived with "Network: testnet",
      and the network is mixed into the seed. The .env RELAYER WALLET block
      only accepts testnet keys.
    - Separate Uniswap: the testnet Uniswap file is never read on a mainnet
      chain id, and deploy-uniswap.js and e2e.js refuse to run on one.
      Mainnet uses Uniswap's own deployment (helpers/uniswap.js).
    - Before mainnet: a multi-party trusted setup for both circuits, a
      multisig owner (with a timelock for upgrades), a new relayer key, and
      gas limits sized for Monad's prices (4b).
